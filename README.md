# Chemistry Battle Room

เกมเว็บการเรียนรู้วิชาเคมีสำหรับนักเรียน ม.2 เรื่องสารประกอบ พันธะไอออนิก และพันธะโคเวเลนต์

## ฟีเจอร์ในต้นแบบ

- หน้า Home, Academy และ Leaderboard
- สร้างห้องแข่งขันและเข้าร่วมห้องด้วยรหัส
- ระดับ Easy, Normal, Hard และ Impossible
- คำถามแบบสุ่ม พร้อมจับเวลา คะแนน Streak และเฉลยทันที
- หน้าสรุปผลการแข่งขัน
- Chem Tip สุ่มแสดงระหว่างเปลี่ยนหน้า/รอเกม
- Responsive รองรับมือถือ

## วิธีเปิดเกม

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที หรือเผยแพร่ repository นี้ด้วย GitHub Pages เพื่อรับลิงก์สาธารณะ

> หมายเหตุ: เวอร์ชันนี้เป็นต้นแบบฝั่งหน้าเว็บ ห้องยังเป็นการจำลองบนเครื่องเดียว ยังไม่ได้เชื่อมระบบผู้เล่นหลายคนแบบเรียลไทม์
